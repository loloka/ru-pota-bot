# История изменений (Changelog)

## [1.1.0] - 2026-09-02
### Добавлено
- **Система персональных подписок (`/sub`)**:
  - Подписка на радиолюбительские позывные (`callsign`) с валидацией по шаблонам.
  - Подписка на референции парков POTA (`park`) с онлайн-проверкой существования через официальное API.
  - Интерактивная Wizard-сцена добавления подписок и удобное Inline-меню для удаления.
  - Интеграция с кнопкой "🔔 Мои подписки" в главном меню бота.
- **Оповещения в фоновом воркере (`clusterWorker`)**:
  - Мгновенные персональные уведомления в ЛС о появлении друзей (`🚨 Ваш друг...`) и активности в парках (`🏞 Новая активность в отслеживаемом парке...`).
  - Дедупликация рассылки для пользователей с несколькими пересекающимися подписками.
- **Отказоустойчивость сети**:
  - Увеличен таймаут HTTP-клиента POTA API до 25 000 мс для стабильной работы при медленном соединении.

---

## [1.0.0] - Базовый MVP
### Добавлено
- Полноценный Wizard для создания спота (`/spot`).
- Интеграция с POTA API (`api.pota.app/spot` и `api.pota.app/park`).
- Функция **Авто-респота**: отправка текущего спота 3 раза каждые 10 минут.
- Управление спотами: изменение частоты, модуляции, мощности, комментария или полное удаление.
- Вывод богатой статистики профиля POTA (`/stats`).
- Поиск детальной информации по паркам и ТОП-охотникам (`/park`).
- Модерация чата (`/ban`, `/kick`, `/mute`).
- Авто-очистка чата от системных сообщений ("Пользователь присоединился") с временным красивым приветствием.
- Парсер для кластера `clusterWorker`, транслирующий новые споты из RU-сегмента POTA в канал.
