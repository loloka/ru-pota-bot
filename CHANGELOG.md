# История изменений (Changelog)

## [1.11.3] - 2026-09-04 (POTA API Rate Limiting Defense & Author Branding)
### Исправлено
- **Защита от сброса HTTP/2 соединений (Stream Aborted / Rate Limiting)**:
  - Фоновое обновление парков POTA (`refreshParksFromApi`) переведено с параллельного залпа на последовательные запросы с паузой в 2 секунды между странами (`RU`, `BY`, `KZ`). Это полностью устранило блокировки Cloudflare и ошибки `stream has been aborted`.
  - Стартовое фоновое обновление отложено на 10 минут после запуска, чтобы не создавать конкуренцию за канал во время старта Telegram-бота и первого опроса кластера.
  - Подавлен спам ошибок `404 Not Found` в консоли при поиске несуществующих позывных в `potaApi.getStats`.
### Добавлено
- **Брендирование и обратная связь в TMA**:
  - В футере бокового меню добавлена информация об авторе (**R9OGL**) и прямая ссылка на Telegram **@r9ogl** для предложений и вопросов.

## [1.11.2] - 2026-09-04 (Guest Lookup TypeError Fix & Directory Chips Cleanup)
### Исправлено
- **Ошибка 500 Internal Server Error при поиске позывных и парков в гостевом режиме**:
  - Устранена ошибка `TypeError: Cannot read properties of null (reading 'id')` в эндпоинтах `GET /api/tma/lookup/callsign/:callsign` и `GET /api/tma/lookup/park/:ref`, возникавшая при проверке подписки у неавторизованных посетителей сайта. Теперь `isSubscribed` безопасно возвращает `false` для гостей.
- **Очистка быстрых подсказок в Справочнике**:
  - Полностью удалена неактуальная кнопка `RA3ATX`. Для гостей доступны проверенные позывные самых активных активаторов POTA (`R2BBX`, `UA9OTW`), а для авторизованных радиолюбителей — их собственный позывной `(Я)`.

## [1.11.1] - 2026-09-04 (Map Parks Resilience & Offline Dataset Fallback)
### Исправлено
- **Отображение парков России (RU) и Беларуси (BY) на интерактивной карте Mini App**:
  - Устранена ошибка, из-за которой при сбое или таймауте внешнего API `api.pota.app` на карте оставались видны только парки Казахстана (`KZ-`), а парки `RU-` и `BY-` обнулялись на 2 часа.
  - Добавлен статический оффлайн-датасет `src/data/parks_fallback.json` на 668 подтверждённых парков (500 `RU-`, 143 `BY-`, 25 `KZ-`). При старте сервера карта мгновенно инициализируется полным набором парков с нулевой задержкой.
  - Разделено кеширование по программам (`RU`, `BY`, `KZ`): если запрос к одной из стран завершается сбоем, существующие парки этой страны сохраняются в памяти и не затираются.
  - Фоновое неблокирующее автообновление парков: запросы к `/api/tma/parks` теперь отвечают мгновенно из памяти без подвисания интерфейса карты.
  - Добавлен официальный заголовок `User-Agent` (`RU-POTA-Bot/1.11.1`) и увеличен таймаут запросов до 30 секунд для предотвращения блокировок со стороны Cloudflare.

    - `GET /api/tma/spots` — кластер спотов в реальном времени с фильтрацией (RU/Мир, диапазоны, моды, поиск) и in-memory кэшированием на 15 секунд для защиты `api.pota.app`.
    - `POST /api/tma/spots` — публикация спота одобренным оператором с записью в SQLite, трансляцией в канал активности и рассылкой персональных алертов подписчикам.

    - `GET /api/tma/subscriptions`, `POST`, `DELETE` — полноценное управление персональными подписками в SQLite.
    - `POST /api/tma/callsign/request` — отправка заявки на привязку или смену позывного.
  - **API Клиент (`src/webapp/src/services/api.js`)**: Подключение всех экранов React к живому API с автоматической передачей учетных данных Telegram.

  - **Безопасное экранирование HTML**: Корректная обработка меток времени (`&lt; 1 мин назад`) и экранирование спецсимволов.
  - **Интерактивные ссылки и формат**: Позывные ведут на профиль `https://next.pota.app/profile/...` (с очисткой дробей `/P`, `/M`), парки — на `https://next.pota.app/park/...`. Частоты приводятся к МГц с 3 знаками (`XX.XXX MHz`).
