# История изменений (Changelog)

## [1.6.0] - 2026-09-03 (On Air Stations & Smart Unified Feed)
### Добавлено
- **Команда `/onair` («Кто в эфире прямо сейчас»)**: Мгновенная сводка всех станций в эфире прямо сейчас с кликабельными ссылками на сайт POTA.
  - **Единый сводный режим («RU/СНГ + МИР»)**: При наличии активных станций из домашнего региона (`ALLOWED_PREFIXES`, по умолчанию `RU-,BY-,KZ-`) за последние 40 минут они гордо выводятся в самом верху сообщения (`🌲 НАШ РЕГИОН`), а сразу под ними выводятся свежие станции мира (`🌍 ВЕСЬ МИР`, топ-10). Если в домашнем регионе временное затишье — бот выводит вежливое уведомление и топ-15 станций мирового эфира за 15 минут.
  - **Интерактивный переключатель режимов**: Инлайн-кнопки `🇷🇺 Только RU/СНГ` ⟷ `🌐 RU/СНГ + МИР` для моментальной фильтрации только по домашнему региону и быстрого возврата к общему списку.
  - **Комментарии и споттеры**: К каждому споту выводятся комментарии активатора/охотников (`💬`) и позывной споттера (`[CALL]` или `👤 Споттер: CALL`). Длинные комментарии аккуратно усекаются.
  - **Полная поддержка респотов**: Отслеживаются и отображаются все респоты на разных диапазонах и от разных корреспондентов, сохраняя динамику эфира.
  - **Строгая защита прав в группах**: Все кнопки управления (`🔄 Обновить`, переключение режимов и `❌ Удалить сообщение`) в группах защищены и доступны только автору запроса, `ADMIN_ID` и администраторам чата.
  - **Безопасное экранирование HTML**: Корректная обработка меток времени (`&lt; 1 мин назад`) и экранирование спецсимволов.
  - **Интерактивные ссылки и формат**: Позывные ведут на профиль `https://next.pota.app/profile/...` (с очисткой дробей `/P`, `/M`), парки — на `https://next.pota.app/park/...`. Частоты приводятся к МГц с 3 знаками (`XX.XXX MHz`).
- **Кнопка меню «📻 Кто в эфире»**: Добавлена в главное меню постоянной клавиатуры на предпоследнюю позицию перед «❓ Справка».
- **Смена позывного в `/start`**: Для одобренных пользователей команда `/callsign` представлена как «Сменить позывной (при необходимости)».
- **Поддержка групп и супергрупп**: При вызове `/onair` в группе сообщение пользователя автоматически удаляется (`deleteUserMessage`), а ответ бота можно закрыть по кнопке удаления.
- **Синхронизация документации**: Команда добавлена в `/help`, `/start`, `COMMANDS.md`, `README.md` и `README.en.md`.

## [1.5.0] - 2026-09-03 (Web Admin 2.0 Polish & Interactive Links)
### Добавлено
- **Кликабельные ссылки в статистике (`/stats`) и справке по парку (`/park`)**: Референции парков (напр. `RU-0065`) теперь оформлены ссылками на `https://next.pota.app/park/...`, а позывные охотников и активаторов (первый активатор, лидер, крайний активатор, топ охотников) — прямыми ссылками на профили `https://next.pota.app/profile/...`.
- **AJAX-модерация в веб-панели**: Одобрение заявок, отклонение (с указанием причины через диалог) и удаление пользователей переведены на AJAX без перезагрузки страницы, с плавной анимацией удаления строк и Toast-уведомлениями.
- **Интеграция профилей Telegram**: Подгрузка аватарок, имени, фамилии и `@username` пользователей через Telegram Bot API с заглушками ui-avatars.
- **Интерактивная Live Консоль**: Просмотр логов в реальном времени с защитой от циклических структур, экранированием HTML и авто-скроллом.
- **Постоянные сессии (`cookie-session`)**: Авторизация администратора сохраняется при перезапусках демона/бота.

### Исправлено
- **Критический фикс синтаксиса в браузере**: Исправлен перенос строки `\n\n` внутри строковых литералов генератора HTML, приводивший к `Uncaught SyntaxError: Invalid or unexpected token` и блокировке всех скриптов панели.
- **Фикс удаления пользователей в БД**: Добавлено строгое приведение типов `Number(id)` для сопоставления с целочисленным первичным ключом SQLite.
- **Безопасный логгер**: Метод `captureLog` защищен от сбоев `JSON.stringify` при перехвате сложных и циклических объектов Telegraf (`ctx`).
- **Сетевая устойчивость API**: Обработчики действий в веб-панели отдают чистый JSON вместо редиректов.

## [1.4.0] - 2026-09-03 (Web Admin 2.0 & Profiles)
### Добавлено
- **Профили пользователей в админке**: Теперь вкладка "Пользователи" подтягивает Имя, Фамилию, @username и аватарку напрямую из Telegram API.
- **Современный UI**: Внедрен SweetAlert2 для всех окон подтверждения. Добавлены плавные анимации.
- **Поддержка Cookie-Session**: Авторизация в веб-панели теперь сохраняется между перезапусками сервера.
- **Авто-обновление спотов**: Вкладка "Споты" в админке автоматически обновляется каждые 5 секунд.
- **Заглушка POTA API**: MOCK_POTA_API=true для блокировки отправки спотов на api.pota.app локально.
### Исправлено
- Починено зависание админки при невозможности загрузить данные о пользователе.
- Решена проблема с зависанием/недоступностью inline-кода onclick через переход на глобальный Event Delegation.

## [1.3.0] - 2026-09-03
### Изменено
- **Web Admin 2.0**: Полный редизайн локальной веб-панели управления.
  - Переход на профессиональный UI-фреймворк (Bootstrap 5).
  - Внедрена сессионная авторизация (`express-session`) со страницей `/login` и логаутом.
  - Добавлена вкладка "Споты" с возможностью просмотра всех спотов и их удаления из Telegram-канала прямо через браузер.
  - Добавлена "Live Консоль" (кольцевой буфер на 200 событий бота) с обновлениями в реальном времени.
- В таблицу `spots` добавлена колонка `msg_id` для отслеживания отправленных ботом сообщений в канал и их последующего удаления.
## [1.2.2] - 2026-09-03
### Безопасность
- **Защита веб-панели (Anti-Bruteforce)**: Добавлено ограничение попыток входа (Rate Limiting) для Basic Auth. Теперь после 5 неудачных попыток ввода пароля IP-адрес злоумышленника блокируется на 15 минут.

## [1.2.1] - 2026-09-03
### Добавлено
- **Поиск по позывному**: В главное меню добавлена кнопка «🔍 Поиск позывного» с отдельной Wizard-сценой для быстрого поиска чужой статистики.
- **Самоочистка справки**: Команда `/help` и кнопка «❓ Справка» при использовании в общей группе теперь удаляют сообщение пользователя и автоматически скрывают ответ бота через 2 минуты, чтобы не засорять чат.

### Исправлено
- Исправлено исчезновение главного меню («📡 Управление спотами», «📊 Моя статистика» и др.) после отмены действий (`/cancel`) во всех Wizard-сценах. Главная клавиатура теперь всегда надежно возвращается на место.

## [1.2.0] - 2026-09-02 (Релиз-кандидат)
### Добавлено
- **Рассылка сообщений от имени бота**: В локальную веб-панель добавлена функция отправки текстовых сообщений (Broadcast) в основную группу (`MAIN_CHAT_ID`) или в канал активности (`ACTIVITY_CHANNEL_ID`).
- **Авто-закреп сообщений**: В веб-панели появилась галочка «📌 Закрепить сообщение» для автоматического пина постов в канале.

### Исправлено
- Исправлена ошибка `chat not found` при рассылках из админки (добавлена авто-нормализация ID чатов, подстановка префикса `-100`).
- Исправлено «проглатывание» инлайн-кнопок одобрения/отклонения заявок, если администратор в этот момент находился внутри сцены (например, при оформлении спота).
- Улучшены и стали более понятными тексты справки (`/start`, `/help`) и сообщения об ошибках для команды `/stats`.


## [1.1.1] - 2026-09-02 (Hotfixes & Proxies)
### Добавлено
- **Поддержка SOCKS5-прокси (VLESS/Tor)** для обхода агрессивных блокировок и ТСПУ.
- **Поддержка HTTP-зеркал (Cloudflare Workers)** через `TG_API_ROOT`.
- Обработчики для кнопки "❓ Справка" и команды `/help` с контактными данными для бета-тестирования.
### Исправлено
- Исправлено зависание бота (ETIMEDOUT) при работе через Cloudflare за счет добавления `Keep-Alive` агента, предотвращающего блокировку по TCP SYN со стороны провайдера.
- Уменьшен таймаут Long Polling до 20 секунд для совместимости с ограничениями Cloudflare Workers.
- Исправлено зависание Wizard-сцен (в т.ч. парков), если пользователь вводил случайную команду во время ожидания ввода.
- Исправлено отсутствие ответа на кнопку "📝 Регистрация" в меню.
- Защищена веб-панель администратора с помощью Basic HTTP Authentication.

## [1.0.0] - Базовый MVP
### Добавлено
- Полноценный Wizard для создания спота (`/spot`).
- Интеграция с POTA API (`api.pota.app/spot` и `api.pota.app/park`).
- Функция **Авто-респота**: отправка текущего спота 3 раза каждые 10 минут.
- Управление спотами: изменение частоты, модуляции, мощности, комментария или полное удаление.
- Вывод богатой статистики профиля POTA (`/stats`).
- Поиск детальной информации по паркам и ТОП-охотникам (`/park`).
- Модерация чата (`/ban`, `/kick`, `/mute`).
- Авто-очистка чата от системных сообщений ("Пользователь присоединился") с временным красивым приветствием.
- Парсер для кластера `clusterWorker`, транслирующий новые споты из RU-сегмента POTA в канал.
