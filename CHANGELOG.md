## [1.16.64] - 2026-09-22 (Isolate Runtime POTA Cache to Gitignored data/parks_cache.json)
### Исправлено и улучшено
- **Изоляция runtime-кэша парков (`ooptService.js`, `tmaApi.js`, `potaAuditService.js`)**:
  - Ранее бот при синхронизации с POTA API перезаписывал `src/data/parks_fallback.json`, отслеживаемый в Git, из-за чего последующие вызовы `git pull` и команды `potaupd` блокировались сообщением `error: Your local changes to the following files would be overwritten by merge`.
  - Все динамические обновления парков из API теперь сохраняются в изолированный файл `data/parks_cache.json` в каталоге `data/`, который изначально находится в `.gitignore`.
  - Статический файл `src/data/parks_fallback.json` остается эталонным неизменяемым датасетом при первом развертывании.
  - При запуске и работе бот автоматически проверяет наличие `data/parks_cache.json` и использует его, а при его отсутствии мягко переключается на базовый `src/data/parks_fallback.json`.
  - Теперь `git pull` и скрипт `potaupd` никогда не будут конфликтовать с локально сохраненным кэшем парков.
- **Синхронизация версий**:
  - Версия обновлена до `1.16.64` (`package.json`, `potaApi.js`, `src/bot/index.js`, `README.md`, `README.en.md`, `CHANGELOG.md`).

- **Поиск по позывному**: В главное меню добавлена кнопка «🔍 Поиск позывного» с отдельной Wizard-сценой для быстрого поиска чужой статистики.
- **Самоочистка справки**: Команда `/help` и кнопка «❓ Справка» при использовании в общей группе теперь удаляют сообщение пользователя и автоматически скрывают ответ бота через 2 минуты, чтобы не засорять чат.

### Исправлено
- Исправлено исчезновение главного меню («📡 Управление спотами», «📊 Моя статистика» и др.) после отмены действий (`/cancel`) во всех Wizard-сценах. Главная клавиатура теперь всегда надежно возвращается на место.

## [1.2.0] - 2026-09-02 (Релиз-кандидат)
### Добавлено
- **Рассылка сообщений от имени бота**: В локальную веб-панель добавлена функция отправки текстовых сообщений (Broadcast) в основную группу (`MAIN_CHAT_ID`) или в канал активности (`ACTIVITY_CHANNEL_ID`).
- **Авто-закреп сообщений**: В веб-панели появилась галочка «📌 Закрепить сообщение» для автоматического пина постов в канале.

### Исправлено
- Исправлена ошибка `chat not found` при рассылках из админки (добавлена авто-нормализация ID чатов, подстановка префикса `-100`).
- Исправлено «проглатывание» инлайн-кнопок одобрения/отклонения заявок, если администратор в этот момент находился внутри сцены (например, при оформлении спота).
- Улучшены и стали более понятными тексты справки (`/start`, `/help`) и сообщения об ошибках для команды `/stats`.


## [1.1.1] - 2026-09-02 (Hotfixes & Proxies)
### Добавлено
- **Поддержка SOCKS5-прокси (VLESS/Tor)** для обхода агрессивных блокировок и ТСПУ.
- **Поддержка HTTP-зеркал (Cloudflare Workers)** через `TG_API_ROOT`.
- Обработчики для кнопки "❓ Справка" и команды `/help` с контактными данными для бета-тестирования.
### Исправлено
- Исправлено зависание бота (ETIMEDOUT) при работе через Cloudflare за счет добавления `Keep-Alive` агента, предотвращающего блокировку по TCP SYN со стороны провайдера.
- Уменьшен таймаут Long Polling до 20 секунд для совместимости с ограничениями Cloudflare Workers.
- Исправлено зависание Wizard-сцен (в т.ч. парков), если пользователь вводил случайную команду во время ожидания ввода.
- Исправлено отсутствие ответа на кнопку "📝 Регистрация" в меню.
- Защищена веб-панель администратора с помощью Basic HTTP Authentication.

## [1.1.0] - 2026-09-02
### Добавлено
- **Система персональных подписок (`/sub`)**:
  - Подписка на радиолюбительские позывные (`callsign`) с валидацией по шаблонам.
  - Подписка на референции парков POTA (`park`) с онлайн-проверкой существования через официальное API.
  - Интерактивная Wizard-сцена добавления подписок и удобное Inline-меню для удаления.
  - Интеграция с кнопкой "🔔 Мои подписки" в главном меню бота.
- **Оповещения в фоновом воркере (`clusterWorker`)**:
  - Мгновенные персональные уведомления в ЛС о появлении друзей (`🚨 Ваш друг...`) и активности в парках (`🏞 Новая активность в отслеживаемом парке...`).
  - Дедупликация рассылки для пользователей с несколькими пересекающимися подписками.
- **Отказоустойчивость сети**:
  - Увеличен таймаут HTTP-клиента POTA API до 25 000 мс для стабильной работы при медленном соединении.

## [1.0.0] - Базовый MVP
### Добавлено
- Полноценный Wizard для создания спота (`/spot`).
- Интеграция с POTA API (`api.pota.app/spot` и `api.pota.app/park`).
- Функция **Авто-респота**: отправка текущего спота 3 раза каждые 10 минут.
- Управление спотами: изменение частоты, модуляции, мощности, комментария или полное удаление.
- Вывод богатой статистики профиля POTA (`/stats`).
- Поиск детальной информации по паркам и ТОП-охотникам (`/park`).
- Модерация чата (`/ban`, `/kick`, `/mute`).
- Авто-очистка чата от системных сообщений ("Пользователь присоединился") с временным красивым приветствием.
- Парсер для кластера `clusterWorker`, транслирующий новые споты из RU-сегмента POTA в канал.
