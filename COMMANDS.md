# Команды Telegram бота RU-POTA 🤖📡

Здесь представлен полный список команд, поддерживаемых ботом.

## Основные команды (для всех пользователей)
Эти команды можно отправлять боту в личные сообщения.

* `/start` — Запуск бота, приветствие и регистрация позывного. Если позывной уже есть, просто открывает главное меню.
* `/spot` — Интерактивный мастер создания или редактирования спота.
* `/stats` или `/stats [позывной]` — Просмотр подробной POTA-статистики (своей или чужой).
* `/park [референция]` — Вывод информации о парке по номеру (например, `/park RU-0100`).
* `/sub` или `/sub [позывной|парк]` — Управление персональными подписками на появление позывных друзей или активности в любимых парках POTA.

## Команды модерации (только для администраторов)
Эти команды работают в групповых чатах, где бот является администратором. Команды нужно отправлять **в ответ (Reply)** на сообщение нарушителя.

* `/ban` — Блокирует пользователя навсегда (добавление в ЧС).
* `/kick` — Исключает пользователя из группы (без добавления в ЧС, может сразу вернуться по ссылке).
* `/mute` — Запрещает пользователю отправлять сообщения в группе.

## Кнопки меню
Вместо ввода команд можно использовать удобное меню кнопок в личных сообщениях:
* **📡 Управление спотами** (аналог `/spot`)
* **📊 Моя статистика** (аналог `/stats`)
* **🏞 Инфо по парку** (аналог `/park`)
* **🔔 Мои подписки** (аналог `/sub`)
* **❓ Справка** — Краткая помощь.
