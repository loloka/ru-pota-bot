# Инструкция по развертыванию RU-POTA бота

## Требования
- Node.js (v18+)
- NPM или Yarn
- Токен Telegram бота (от @BotFather)
- ID канала для публикации спотов (должен начинаться с -100)

## Установка

1. Склонируйте репозиторий.
2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env` в корне проекта и заполните его по примеру `.env.example`:
```env
BOT_TOKEN=ваш_токен_бота
ACTIVITY_CHANNEL_ID=-1001234567890
```
*Примечание: Убедитесь, что бот добавлен в канал активности с правами администратора (для публикации, редактирования и удаления сообщений).*

## Настройка обхода блокировок (v2rayA / VLESS)
Если ваш хостинг-провайдер блокирует доступ к API Telegram (или режет соединения к Cloudflare), необходимо поднять локальный SOCKS5-прокси через клиент `v2rayA`:
1. Установите `v2rayA` на сервер и включите службу: `sudo systemctl enable --now v2raya`.
2. Зайдите в веб-панель `http://<IP-СЕРВЕРА>:2017` и импортируйте рабочую ссылку VLESS (XTLS-Reality).
3. Запустите сервер в v2rayA (кнопка Ready -> Running).
4. В файле `.env` пропишите `TG_PROXY=socks5h://127.0.0.1:20170`.

## Панель модерации (Web Admin)
Бот автоматически запускает локальный веб-сервер для администрирования заявок на регистрацию позывных.
- **Порт:** 3005 (по умолчанию)
- **Доступ:** Basic Auth (укажите пароль в `.env` переменной `ADMIN_PASSWORD`)
- **Адрес:** `http://localhost:3005` (пробросьте через Nginx для доступа извне).

## Запуск в Production (PM2)

Рекомендуется использовать PM2 для демонизации процесса:
```bash
npm install -g pm2
pm2 start src/bot/index.js --name ru-pota-bot
pm2 save
pm2 startup
```

Скрипт автообновления: используйте готовый bash-скрипт `./update-bot.sh` для `git pull` и перезапуска PM2 с обновлением переменных среды (`--update-env`).
