# Инструкция по развертыванию RU-POTA бота

## Требования
- Node.js (v18+)
- NPM или Yarn
- Токен Telegram бота (от @BotFather)
- ID канала для публикации спотов (должен начинаться с -100)

## Установка

1. Склонируйте репозиторий.
2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env` в корне проекта и заполните его по примеру `.env.example`:
```env
BOT_TOKEN=ваш_токен_бота
ACTIVITY_CHANNEL_ID=-1001234567890
```
*Примечание: Убедитесь, что бот добавлен в канал активности с правами администратора (для публикации, редактирования и удаления сообщений).*

## Запуск

**Режим разработки (с автоперезагрузкой):**
```bash
npm run dev
```

**Продуктовый режим:**
```bash
npm start
```
Бот использует локальную базу данных SQLite. Файл БД (`pota.db`) автоматически создастся в папке `data/` при первом запуске.
