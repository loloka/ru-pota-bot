# RU-POTA Telegram Bot 🌲📡

Telegram-бот для интеграции с программой **Parks on the Air (POTA)**. Создан специально для русскоязычного сообщества радиолюбителей. Бот позволяет отправлять, редактировать и отслеживать споты, получать подробную статистику пользователей и информацию по паркам прямо из Telegram.

## Основные возможности MVP
- 📡 **Отправка спотов:** Полноценная анкета создания спота с валидацией парков, удобной клавиатурой для модуляций и авто-проставлением RDA.
- 🔄 **Авто-респот:** Возможность автоматически отправлять спот на POTA кластер 3 раза каждые 10 минут (при работе в эфире).
- ✏️ **Управление спотами:** Возможность изменить любой пункт активного спота (частоту, комментарий, мощность) или удалить его. Изменения моментально транслируются в канал и на сайт POTA.
- 📊 **Моя статистика:** Красивая генерация карточки профиля радиолюбителя с сайта POTA (награды, QSO, активации, последние сработанные станции).
- 🏞 **Инфо по парку:** Поиск подробной информации по референции парка, генерация карты (Яндекс.Карты) и топ-охотников.
- 🛡 **Модерация:** Команды `/ban` и `/mute` для поддержания порядка в главном сообществе.
- 🧹 **Авто-очистка чата:** Все системные сообщения о входе/выходе удаляются, бот приветствует новичков и через 2 минуты удаляет своё приветствие, чтобы не засорять чат. Сообщения-команды удаляются через 7 секунд.

## Команды бота
- `/start` — Запуск бота, регистрация позывного и вызов главного меню.
- `/spot` — Оформить новый спот или управлять текущим.
- `/stats` — Просмотр богатой статистики профиля POTA.
- `/park [RU-1234]` — Информация о парке.
- `/ban` — (Для админов) Заблокировать пользователя (через reply).
- `/mute` — (Для админов) Заглушить пользователя (через reply).

## Структура проекта
- `src/bot` — Основная логика бота (сцены, команды, обработчики).
- `src/api` — Интеграция с POTA API (отправка спотов, получение статистики).
- `src/db` — Работа с локальной базой данных SQLite.
- `src/services` — Фоновые задачи (например, clusterWorker.js для трансляции спотов с сайта в канал).
