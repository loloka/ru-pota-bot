Многофункциональный Telegram-бот и платформа для радиолюбительского сообщества дипломной программы **Parks on the Air (POTA)**. Создан специально для русскоязычных активаторов и охотников за парками.

Бот объединяет Telegram-сообщество, официальный кластер POTA, систему персональных подписок на радиолюбителей и современную веб-панель управления.

## ✨ Ключевые возможности

### 📡 1. Интерактивный споттинг (/spot)
- **Пошаговый мастер (Wizard):** Создание спота с выбором статуса (*СЕЙЧАС В ЭФИРЕ* или *ПЛАНИРУЮ*), авто-подтягиванием данных парка из официального API, вводом RDA-района, выбором модуляций (`SSB`, `CW`, `FT8`, `FT4`, `FM` и др.) и мощности.
- **Публикация в кластер и канал:** Спот мгновенно транслируется в [@pota_activity](https://t.me/pota_activity) и при необходимости отправляется в официальный международный кластер POTA.
- **Авто-респот (Keep-Alive):** Бот может автоматически повторять спот 3 раза каждые 10 минут, пока активатор работает в поле.
- **Управление активным спотом:** Возможность в один клик изменить частоту, комментарий, модуляцию или снять спот с удалением сообщения из канала.

### 🔔 2. Персональные подписки и мгновенные алерты (/sub)
- **Алерты на позывные:** Мгновенное оповещение в ЛС, когда ваш друг или редкий активатор выходит в эфир:  
  `🚨 Ваш отслеживаемый радиолюбитель R9OGL сейчас в эфире!`
- **Алерты на парки:** Уведомления об активности в любимых или редких референциях (напр. `RU-0001`, `RU-0073`).
- **Умная дедупликация:** Никакого спама — бот отслеживает повторные споты и отправляет уведомление только при реальном появлении в эфире.
- **Быстрое управление:** Inline-кнопки управления списком подписок прямо в чате с ботом.

### 🌐 3. Фоновый мониторинг кластера (Cluster Worker)
- Автоматический опрос `api.pota.app` каждую минуту.
- Гео-фильтрация по префиксам стран (по умолчанию `RU-`, `BY-`, `KZ-`).
- Трансляция новых спотов в новостной канал и рассылка персональным подписчикам.

### 📊 4. Статистика и справочник парков
- **`/stats [позывной]`:** Полная карточка профиля активатора и охотника (количество активаций, уникальных парков, QSO по модам, награды, крайние поездки).
  - **Интерактивные ссылки:** Референции парков (напр. [RU-0065](https://next.pota.app/park/RU-0065)) и позывные радиолюбителей автоматически ведут на портал `next.pota.app`.
- **`/park [код]`:** Подробная карточка парка с названием, координатами, RDA, статистикой и динамической картой местности.

### 📻 5. Кто в эфире прямо сейчас (/onair)
- **Мгновенная сводка:** Компактный список станций в эфире прямо сейчас с кликабельными ссылками на профили операторов и карточки парков.
- **Интерактивные фильтры по диапазонам и модам (галочками):** Настраиваемые кнопки-чекбоксы для любого сочетания диапазонов (160m-70cm) и мод (CW, SSB, FT8, FM, DIGI). Пресет «40, 30, 20 CW», сброс в 1 клик и сохранение предпочтений в БД.
- **Умный авто-режим (Smart Fallback):** Показывает станции RU/СНГ за последние 40 минут; если в домашнем регионе затишье — автоматически выводит топ-10 самых свежих станций мира за 15 минут.
- **Инлайн-переключатель:** Кнопка переключения между режимами `🌍 Весь мир` и `🇷🇺 Только RU/СНГ`, кнопка быстрого обновления `🔄` и кнопка `❌ Удалить`.

### 🖥 6. Веб-панель управления (Web Admin 2.0)
Встроенный защищенный веб-интерфейс на Express 5 и Bootstrap 5 (`http://localhost:3000`):
- 🔐 **Сессионная авторизация:** Защита паролем с персистентными сессиями (`cookie-session`) и защитой от перебора (Anti-Bruteforce rate limiting).
- 👤 **Интеграция Telegram-профилей:** Автоматическая подгрузка аватарок, имени, фамилии и `@username` пользователей из Telegram.
- ⚡ **AJAX-модерация в 1 клик:** Одобрение заявок, отклонение с указанием причины и удаление пользователей без перезагрузки страницы (модальные окна SweetAlert2).
- 📻 **Управление спотами:** Просмотр ленты спотов с авто-обновлением каждые 5 секунд и удалением любого спота вместе с постом в канале.
- 💻 **Live Консоль активности:** Кольцевой буфер на 200 последних событий бота в реальном времени с защитой от сбоев JSON и фильтрацией ANSI-кодов.
- 📢 **Массовая рассылка (Broadcast):** Отправка важных объявлений в канал или группу от имени бота с возможностью автоматического закрепления (pin).

### 📱 7. Telegram Mini App (TMA / Web App)
Современный встроенный веб-интерфейс в эстетике тёмной темы (Deep Slate / Matryoshka VPN, `http://localhost:3000/app`):
- 🏠 **Главная (Dashboard):** Приветствие, карточка статуса эфира с таймером авто-респота, **Справочник POTA (поиск по позывному `/stats` и парку `/park` с автодополнением, тумблером подписки в 1 клик, маршрутами и переходом на карту)**, горизонтальный слайдер активных станций, быстрая статистика.
- 📻 **В эфире (Live Cluster):** Кластер с мгновенными фильтрами по диапазонам (40m, 20m...), видам модуляции (SSB, CW, FT8...), домашнему региону и миру.
- 🗺 **Интерактивная карта (Leaflet):** Официальные WMS-слои R1CF (RDA 2025, RAZA, RAFA, QTH, SOTA, RLHA), чистые тайлы без водяных знаков, мульти-маршруты (Яндекс, 2ГИС, OsmAnd) и база офлайн-карт OsmAnd PlusM.
- 🔔 **Управление подписками:** Сегментное разделение (Позывные / Парки), тумблер алертов в ЛС, удаление в 1 клик.
- 👤 **Профиль и настройки:** Прогресс активатора и охотника, заявка на смену позывного, переключатель Haptic Feedback (тактильный отклик Telegram).
- 📖 **Руководство разработчика:** Подробная шпаргалка по командам, сборке, Browser Mock и подключению кнопки меню в [`docs/MINIAPP_GUIDE.md`](docs/MINIAPP_GUIDE.md).

### 🛡 8. Чистота чата и модерация
- **Анти-мусор (Gatekeeper):** Автоматическое удаление сервисных сообщений («Пользователь вступил в группу») с временным приветствием (самоудаляется через 2 минуты).
- **Авто-удаление команд:** Команды пользователей в публичной группе удаляются сразу после отправки, сохраняя историю общения чистой.
- **Команды модераторов:** `/ban`, `/kick`, `/mute` через Reply на сообщение нарушителя.

## 🛠 Архитектура и стек технологий

```text
┌─────────────────────────────────────────────────────────────┐
│                    RU-POTA Telegram Bot                     │
├──────────────────────────────┬──────────────────────────────┤
│        Telegram Core         │          Web Admin           │
│  Telegraf 4.x (ES Modules)   │      Express 5 + EJS/HTML    │
│  Wizards & Scenes            │      Bootstrap 5 & SweetAlert│
│  Middlewares & Gatekeeper    │      Live Console Buffer     │
├──────────────────────────────┴──────────────────────────────┤
│                       Data & Services                       │
│  better-sqlite3 (SQLite WAL) │  Axios (POTA API Client)     │
│  Cluster Polling Worker      │  SOCKS5 / Cloudflare Proxy   │
└─────────────────────────────────────────────────────────────┘
```

- **Среда выполнения:** Node.js 18+ (ESM).
- **Telegram фреймворк:** [Telegraf](https://github.com/telegraf/telegraf) 4.16+.
- **База данных:** [better-sqlite3](https://github.com/WiseLibs/better-sqlite3) в режиме повышенной производительности WAL с автоматическими миграциями схемы.
- **HTTP клиент:** Axios с таймаутами 25 000 мс и обработкой сетевых задержек.
- **Обход блокировок:** Поддержка SOCKS5 прокси (`TG_PROXY`) и обратных HTTP-прокси/зеркал Cloudflare Workers (`TG_API_ROOT`).

## 🚀 Быстрый старт (Локально)

### 1. Клонирование репозитория
```bash
git clone https://github.com/loloka/ru-pota-bot.git
cd ru-pota-bot
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Скопируйте файл примера `.env.example` в `.env`:
```bash
cp .env.example .env
```
Заполните обязательные параметры:
```env
BOT_TOKEN=1234567890:ABCDefGhIJklMNopQRstUVwxYZ
MAIN_CHAT_ID=-1001234567890
ACTIVITY_CHANNEL_ID=-1000987654321
ADMIN_ID=123456789
ADMIN_PASSWORD=your_secure_password
```

### 4. Запуск в режиме разработки
```bash
npm run dev
```
Веб-панель управления будет доступна по адресу: `http://localhost:3000` (логин: `admin`, пароль из `.env`).

## 📦 Развертывание на сервере (Ubuntu + PM2)

Подробное пошаговое руководство по установке на VPS, настройке демона PM2, ротации логов и Nginx доступно в документе **[DEPLOY.md](DEPLOY.md)**.

Краткая инструкция:
```bash
git clone https://github.com/loloka/ru-pota-bot.git /opt/potabot
cd /opt/potabot
npm install --production
cp .env.example .env && nano .env
pm2 start src/bot/index.js --name potabot
pm2 save
pm2 startup
```
