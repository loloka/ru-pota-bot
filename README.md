# RU-POTA Telegram Bot 🌲📡

Многофункциональный Telegram-бот для интеграции с международной дипломной программой **Parks on the Air (POTA)**. Создан специально для русскоязычного сообщества радиолюбителей. 

Бот позволяет отправлять, редактировать и отслеживать споты в кластере, подписываться на активность друзей и парков, получать подробную статистику пользователей с интерактивными картами и модерировать чат сообщества.

---

## 🚀 Основные возможности

### 📡 Споттинг и интеграция с POTA API
- **Интерактивный мастер (/spot):** Пошаговая анкета создания спота с валидацией референций парков, авто-подтягиванием RDA и клавиатурой модуляций.
- **Авто-респот:** Фоновая отправка спота в кластер 3 раза каждые 10 минут во время полевой работы.
- **Управление активным спотом:** Моментальное изменение частоты, модуляции, мощности, комментария или полное удаление спота из канала и кластера POTA.

### 🔔 Персональные подписки и алерты (/sub)
- **Подписка на позывные:** Мгновенные уведомления в ЛС, как только интересующий радиолюбитель/активатор появляется в эфире (`🚨 Ваш друг R9OGL сейчас в эфире!`).
- **Подписка на парки:** Отслеживание активности в любимых референциях POTA (`🏞 Новая активность в отслеживаемом парке RU-0001!`).
- **Строгая валидация:** Проверка позывных по радиолюбительским шаблонам (включая дроби) и онлайн-проверка существования парков через официальное POTA API.
- **Интерактивный UI:** Удобное меню с inline-кнопками добавления и удаления подписок в 1 клик.

### 🌐 Мониторинг кластера (Cluster Worker)
- Фоновый воркер опрашивает официальный API POTA раз в минуту.
- Гео-фильтрация префиксов (RU, BY, KZ и др.).
- Дедупликация спотов (защита от спама).
- Автоматическая трансляция спотов в новостной канал и рассылка персональных уведомлений подписчикам.

### 📊 Статистика и справочник парков
- **`/stats [позывной]`:** Генерация подробной карточки профиля POTA (кол-во активаций, QSO, топ сработанных станций, награды).
- **`/park [референция]`:** Полная справка о парке, первый/последний активатор, статистика охотников и автоматическая генерация карты расположения через Яндекс.Карты.

### 🛡 Модерация и чистота чата
- **Админ-команды:** `/ban`, `/kick`, `/mute` (через reply на сообщение нарушителя).
- **Анти-мусор (Gatekeeper):** Автоудаление системных сообщений Telegram ("Пользователь вступил/покинул группу") с отправкой временного приветствия (самоудаляется через 2 минуты).
- **Автоудаление команд:** Команды пользователей в группе удаляются автоматически, чтобы не засорять историю чата.

## 📋 Список команд бота

### Для всех пользователей (в ЛС или группе)
| Команда | Описание |
|---|---|
| `/start` | Запуск бота, приветствие, регистрация позывного и главное меню |
| `/spot` | Оформить новый спот или управлять активным спотом |
| `/sub` | Управление подписками на позывные и парки POTA |
| `/sub [позывной]` | Быстрое добавление/удаление подписки на позывной |
| `/sub [парк]` | Быстрое добавление/удаление подписки на референцию парка |
| `/stats` | Просмотр своей статистики POTA |
| `/stats [позывной]` | Просмотр статистики любого радиолюбителя |
| `/park [референция]` | Информация о парке (например, `/park RU-0073`) |
| `/callsign` | Подать заявку на регистрацию/смену позывного |

### Для администраторов (в группе через Reply)
| Команда | Описание |
|---|---|
| `/ban` | Заблокировать пользователя навсегда |
| `/kick` | Исключить пользователя из группы |
| `/mute` | Запретить пользователю писать сообщения в группе |

## 🛠 Стек технологий
- **Node.js (ES Modules)**
- **Telegraf 4.x** (Scenes, Wizards, Middleware, Inline/Reply Keyboards)
- **better-sqlite3** (быстрая локальная БД в режиме WAL с автомиграциями)
- **Axios** (POTA API REST Client с таймаутом и обработкой сетевых сбоев)
- **dotenv** (Конфигурация окружения)

## 📁 Структура проекта
```text
potabot/
├── data/                  # SQLite база данных (pota.db) - игнорируется git
├── src/
│   ├── api/               # Клиент POTA API (potaApi.js)
│   ├── bot/
│   │   ├── commands/      # Обработчики команд (/start, /stats, /sub, /mod, etc.)

│   │   └── index.js       # Точка входа Telegram-бота

│   ├── services/          # Фоновые воркеры (clusterWorker.js)
│   └── web/               # Веб-сервер админки
├── .env.example           # Шаблон переменных окружения
├── CHANGELOG.md           # История версий

├── DEPLOY.md              # Инструкция по развертыванию на VPS
└── ROADMAP.md             # Дорожная карта проекта
```
