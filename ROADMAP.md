# 🗺️ Дорожная карта разработки: Telegram-бот RU-POTA (ROADMAP)

## 📌 Обзор проекта
Многофункциональный Telegram-бот для радиолюбительского сообщества POTA (Parks on the Air). 
Проект нацелен на автоматизацию модерации, верификацию позывных, агрегацию спотов из кластера POTA, публикацию локальных активаций и создание удобного интерфейса через Telegram Web App (TWA).

---

## 🚀 Этап 1: MVP (Минимально рабочий продукт) - Завершено ✅
> **Цель:** Запустить стабильную базовую версию бота в чате и настроить трансляцию спотов в канал активности.

- [x] **Базовый каркас проекта:** Инициализация Node.js, Telegraf, SQLite. Модульная архитектура.
- [x] **Система авторизации (Gatekeeper):** Команда `/start` (или `/callsign`) для регистрации и получения позывного.
- [x] **Интеграция кластера POTA (Polling Worker):** Фоновый опрос официального API (`clusterWorker.js`). Фильтрация префиксов RU/СНГ. Дедупликация спотов бота. Отправка в канал.
- [x] **Базовая модерация:** Команды `/ban` и `/mute` для администраторов. Автоудаление сервисных системных сообщений Telegram («Пользователь вступил/покинул группу») с красивым временным приветствием.
- [x] **Первичный деплой:** Инициализация Git, DEPLOY.md, README.md, CHANGELOG.md.

---

## ⚡ Этап 2: Пользовательские фичи - В процессе 🔄
> **Цель:** Сделать бота незаменимым ежедневным инструментом для радиолюбителей в поле и дома.

- [x] **Интерактивный споттер (/spot):** Пошаговая анкета (WizardScene). Поддержка ПЛАНИРУЮ и СЕЙЧАС НА СВЯЗИ. Автоподтягивание данных парка из POTA API. Отправка спотов напрямую на сайт POTA.
- [x] **Управление и Авто-респот:** Возможность менять частоту/комментарий или удалять спот. Автоматический респот каждые 10 минут.
- [x] **Справочный блок:**
  - `/stats [позывной]` — запрос статистики из API POTA с кнопками.
  - `/park [референс]` — подробная карточка парка с генерацией Яндекс.Карт и топ-охотников.
- [x] **Персонализация и алерты (/sub):**
  - Подписка на уведомления по позывному друга/активатора и по референциям парков POTA с валидацией позывных и проверкой существования парков через API. Бот присылает персонализированное уведомление в ЛС, как только спот появляется на кластере.

## 📱 Этап 3: Админка и Telegram Web App (TWA) - Планируется 📅
> **Цель:** Превратить бота в современное веб-приложение внутри Telegram с визуальной панелью управления.

- [ ] **Динамическая конфигурация (БД):** Перенос статичных параметров из `.env` в БД для управления через бота.
- [ ] **Telegram Web App (TWA):** Открытие интерактивной карты парков и удобной формы подачи спота внутри Telegram.
