# 🗺️ Дорожная карта разработки: Telegram-бот RU-POTA (ROADMAP)

## 📌 Обзор проекта
Многофункциональный Telegram-бот для радиолюбительского сообщества POTA (Parks on the Air). 
Проект нацелен на автоматизацию модерации, верификацию позывных, агрегацию спотов из кластера POTA, публикацию локальных активаций и создание удобного интерфейса через Telegram Web App (TWA).

---

## 🚀 Этап 1: MVP (Минимально рабочий продукт) - Завершено ✅
> **Цель:** Запустить стабильную базовую версию бота в чате и настроить трансляцию спотов в канал активности.

- [x] **Базовый каркас проекта:** Инициализация Node.js, Telegraf, SQLite. Модульная архитектура.
- [x] **Система авторизации (Gatekeeper):** Команда `/start` (или `/callsign`) для регистрации и получения позывного.
- [x] **Интеграция кластера POTA (Polling Worker):** Фоновый опрос официального API (`clusterWorker.js`). Фильтрация префиксов RU/СНГ. Дедупликация спотов бота. Отправка в канал.
- [x] **Базовая модерация и управление чатом:** Команды `/ban` и `/mute` для администраторов. Постоянные приветствия новых участников (видны всем, не удаляются). Автоматическое открепление спотов по 30-минутному таймеру в канале и группе (`pinManager`).
- [x] **Первичный деплой:** Инициализация Git, DEPLOY.md, README.md, CHANGELOG.md.

## ⚡ Этап 2: Пользовательские фичи - В процессе 🔄
> **Цель:** Сделать бота незаменимым ежедневным инструментом для радиолюбителей в поле и дома.

- [x] **Интерактивный споттер (/spot):** Пошаговая анкета (WizardScene). Поддержка ПЛАНИРУЮ и СЕЙЧАС НА СВЯЗИ. Автоподтягивание данных парка из POTA API. Отправка спотов напрямую на сайт POTA.
- [x] **Управление и Авто-респот:** Возможность менять частоту/комментарий или удалять спот. Автоматический респот каждые 10 минут.
- [x] **Справочный блок:**
  - `/stats [позывной]` — карточка статистики POTA с интерактивными ссылками на сайт `next.pota.app`.
  - `/park [референс]` — подробная карточка парка со ссылками на позывные, генерацией Яндекс.Карт и топ-охотников.
- [x] **Персонализация и алерты (/sub):**
  - Подписка на уведомления по позывному друга/активатора и по референциям парков POTA с валидацией позывных и проверкой существования парков через API. Бот присылает персонализированное уведомление в ЛС, как только спот появляется на кластере.
- [ ] **Полевые фичи для радиолюбителей (Field Ops):**
  - 📍 **Поиск ближайших парков по GPS (Геолокация):** отправка геопозиции со смартфона -> расчет дистанции, азимута и кнопка быстрого построения маршрута в Яндекс.Навигаторе.
  - 🧭 **QTH & RDA калькулятор:** моментальное вычисление QTH-локатора (Grid Square) и RDA-района по текущим координатам активатора.
  - ☀️ **Космическая погода и прохождение (`/solar` / `/prop`):** парсинг индексов SFI, A, K и прогноза прохождения на КВ-диапазонах (80m-10m) по данным NOAA/WWV.
- [ ] **Эфирные и кластерные улучшения:**
  - [x] 📻 **Команда `/onair` («Кто в эфире прямо сейчас»):** компактная сводка активных станций RU/СНГ за последние 40 минут с умным переключением на мировой эфир и **интерактивными фильтрами галочками по диапазонам (160m-70cm) и модуляциям (CW/SSB/FT8/FM)**.
  - [ ] 🌟 **Оповещения об ATNO (All Time New One):** выделенный золотой алерт в канал при активации парка, который еще ни разу не звучал в эфире.
  - 📅 **Календарь экспедиций:** агрегация спотов со статусом «ПЛАНИРУЮ» в сводку на выходные.
- [ ] **Интеграция с логами (ADIF Parser):**
  - Загрузка аппаратного журнала (`.adi`), автоматическая проверка выполнения условий POTA (минимум 10 QSO), расчет статистики и генерация графической карточки-отчета для соцсетей.

## 📱 Этап 3: Полноценная Веб-панель (Web Admin 2.0) и TWA - В процессе 🔄
> **Цель:** Превратить локальную админку в стильный профессиональный дашборд и добавить Telegram Web App (TWA).

- [x] **Редизайн веб-админки (Web Admin 2.0):**
  - [x] Профессиональный UI (Bootstrap 5, SweetAlert2, адаптивные списки).
  - [x] Полноценная сессионная авторизация (`cookie-session`) с сохранением сессии при перезапуске сервера.
  - [x] **Интеграция Telegram-профилей:** автоматическая подгрузка аватарок, имени, фамилии и username через Telegram API.
  - [x] **Live-консоль активности:** просмотр логов входящих команд и фонового воркера в реальном времени прямо из браузера (без SSH на сервер).
  - [x] **Управление спотами:** вкладка активных спотов с возможностью удалять спот с автоматическим удалением постов из канала.
  - [x] **AJAX-модерация пользователей:** быстрое подтверждение, отклонение с указанием причины и удаление пользователей без перезагрузки страницы.
- [x] **Telegram Mini App (TMA / Web App) — Этап 1: Frontend Skeleton & Dark UI Layout** (подробнее в [docs/MINIAPP_GUIDE.md](docs/MINIAPP_GUIDE.md)):
  - [x] Полноценное мобильное SPA-приложение с темной темой (в стиле Matryoshka) и 5 разделами навигации (Bottom Bar).
  - [x] 🏠 **Главная (Дашборд)**: статус текущего спота (ON AIR), быстрый споттинг, статистика и слайдер «Кто в эфире».
  - [x] 📻 **В эфире**: живой кластер с мгновенными фильтрами по диапазонам/модам, регионам (RU/Мир) и поиском.
  - [x] 🗺 **Карта парков**: полноэкранный стилизованный контейнер карты, живые пульсирующие маркеры активных активаций, Bottom Sheet с инфо о парке.
  - [x] 🔔 **Подписки**: интерактивное управление алертами (позывные/парки), тумблер алертов в ЛС и удаление.
  - [x] 👤 **Профиль**: карточка радиолюбителя, статистика активатора/охотника, заявка на смену позывного и переключатель тактильного отклика (Haptic Feedback).
  - [x] Сборка на Vite + React 18 + Tailwind CSS, Telegram WebApp SDK, Browser Dev Mock и раздача через Express по адресу `/app`.
- [x] **Telegram Mini App (TMA / Web App) — Этап 2: Backend API и HMAC-Авторизация**:
  - [x] Мидлвар криптографической валидации `initData` (HMAC-SHA256) в `src/web/tmaAuth.js`.
  - [x] REST API роутер `src/web/tmaApi.js` (`/api/tma/me`, `/spots`, `/subscriptions`, `/callsign/request`).
  - [x] Интеграция POTA API с 15-секундным кэшированием спотов и 10-минутным кэшированием статистики.
  - [x] Публикация спота из TMA с трансляцией в канал активности и рассылкой персональным подписчикам.
  - [x] Подключение клиентского API сервиса `src/webapp/src/services/api.js` ко всем 5 экранам интерфейса.
- [x] **Telegram Mini App (TMA / Web App) — Этап 3: Полноценный интерактив и Карты**:
  - [x] Интеграция Leaflet с темным тайловым слоем CartoDB Dark Matter и светлым CartoDB Voyager.
  - [x] Подключение официальных WMS-слоев геосервера R1CF (`map.r1cf.ru`): Районы RDA (`RDA_2025X`), аномальные зоны RAZA, аэродромы RAFA, сетка QTH/GRID, маяки RLHA, вершины SOTA.
  - [x] Полный реестр 668 парков POTA (RU, BY, KZ) с гарантированным офлайн-датасетом (`parks_fallback.json`), фоновым неблокирующим обновлением и защитой от затирания кеша при сбоях POTA API.
  - [x] Мульти-навигация и построение маршрута к парку: Яндекс Карты, 2ГИС, OsmAnd и копирование GPS координат.
  - [x] Раздел офлайн-навигации: руководство по картам RDA в OsmAnd и прямые ссылки на скачивание APK с `r9old.ru`.
  - [x] **Интерактивный справочник POTA на Главной (Dashboard)**: мгновенный поиск позывных (`/stats`) и парков (`/park`), автодополнение, живой статус эфира, тумблеры подписки в 1 клик, переход к точке на карте и построение маршрута.
  - [x] **Гостевой режим (Guest Mode) и авторизация через Telegram-бота**: открытие приложения вне Telegram в безопасном режиме гостя (без подстановки моков), открытый просмотр кластера и карты, модальное окно авторизации для отправки спотов и личных подписок, безопасный поиск без ошибок `TypeError`.
  - [x] **Настройка Mini App в Telegram BotFather**: Main App во весь экран (`Fullscreen`), брендированный сплэш-экран (SVG-иконка 512x512 + Dark/Light фоны) и прямая ссылка `t.me/ru_pota_bot/app` с промо-баннером 16:9.
