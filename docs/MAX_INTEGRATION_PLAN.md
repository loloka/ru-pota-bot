# Интеграция мессенджера МАКС (Задел на будущее)

Документация API: https://dev.max.ru/docs-api
(Основано на platform-api2.max.ru, поддержка Webhooks и кнопок)

## Идея архитектуры (Микросервисы)
Чтобы не ломать стабильного Telegram-бота, МАКС-интеграцию лучше вынести в отдельный процесс/бота (`maxBot.js`).
Они будут общаться через одну и ту же базу данных SQLite (`data/pota.db`).

### Что потребуется:
1. Создать бота в МАКСе и получить токен.
2. Поднять Express-сервер для прослушивания Webhook от МАКСа (`POST /subscriptions`).
3. Написать клиент для отправки/удаления сообщений через `axios` (REST методы: `POST /messages`, `DELETE /messages`).
4. Написать парсер команд (аналог Telegraf) для обработки `/stats`, `/spot`.
5. Синхронизировать рассылку спотов (Cluster Worker должен кидать споты и в канал TG, и в канал MAX).

Реализация отложена до стабилизации Telegram-версии в Production.
