# 📱 Руководство по Telegram Mini App (RU-POTA TMA) 🌲📡

Полная шпаргалка и практическое руководство для разработчика по работе, запуску, сборке и настройке **Telegram Mini App (Web App)** для проекта **RU-POTA Bot**.

---

## 🎯 1. Что это такое и как это устроено

**Telegram Mini App (TMA)** — это современное веб-приложение (SPA), которое открывается прямо внутри Telegram на смартфонах (iOS, Android) и в десктопном клиенте (Telegram Desktop / macOS).

### 🏛 Архитектура:
```text
┌──────────────────────────────────────────────────────────┐
│                   Telegram Client (UI)                   │
│   iOS / Android / Desktop / Web (внутри WebView)          │
└────────────────────────────┬─────────────────────────────┘
                             │
                             ▼
┌──────────────────────────────────────────────────────────┐
│             Frontend SPA: src/webapp/                    │
│   • Vite 5 + React 18 + Tailwind CSS                     │
│   • Lucide Icons + Telegram WebApp SDK                   │
│   • Browser Dev Mock (для отладки на ПК без Telegram)    │
└────────────────────────────┬─────────────────────────────┘
                             │
             Сборка: npm run webapp:build
                             ▼
┌──────────────────────────────────────────────────────────┐
│             Production Bundle: dist/webapp/              │
│   • index.html, JS-бандл, оптимизированный CSS          │
└────────────────────────────┬─────────────────────────────┘
                             │
            Раздача Express (GET /app, /app/*)
                             ▼
┌──────────────────────────────────────────────────────────┐
│             Node.js Backend: src/web/admin.js            │
│   • Единый порт 3000 (или ваш PORT из .env)              │
│   • Раздает /app (Mini App) и / (Admin Dashboard)        │
└──────────────────────────────────────────────────────────┘
```

## 💻 2. Быстрый старт и команды

Все команды выполняются из корня проекта `potabot/`:

| Команда | Что делает | Когда использовать |
|---|---|---|
| `npm run webapp:dev` | Запуск **Vite Dev Server** на `http://localhost:5173/app/` с мгновенным HMR | При верстке и разработке фронтенда на ПК |
| `npm run webapp:build` | Компиляция React и Tailwind в оптимизированную статику в папку `dist/webapp/` | Перед заливкой на сервер или после правок UI |
| `npm run build` | Алиас для `npm run webapp:build` | Для систем CI/CD и деплоя на сервере |
| `npm run dev` | Запуск Telegram-бота с автоперезагрузкой (`node --watch`) | При разработке бэкенда/бота |
| `npm run start` | Обычный запуск бота и веб-сервера | Запуск в штатном режиме (или через PM2) |

## 🛠 3. Локальная разработка в обычном браузере (Browser Dev Mock)

Вам **не нужно** каждый раз собирать бандл и открывать Telegram, чтобы увидеть изменения!

1. Запустите dev-сервер:
   ```bash
   npm run webapp:dev
   ```
2. Откройте в Chrome / Firefox / Safari:
   👉 **`http://localhost:5173/app/`** (или `http://localhost:3000/app` при запущенном основном боте).
3. В коде настроен **Browser Dev Mock** ([`src/webapp/src/services/telegram.js`](file:///e:/dev/potabot/src/webapp/src/services/telegram.js)):
   - Если открыто вне Telegram, автоматически подставляется профиль тестового оператора: `Алексей (R9OGL)`.
   - Методы тактильного отклика (вибрация `haptic`) и системные методы Telegram безопасно глушатся без ошибок в консоли.
   - Любые правки в файлах `src/webapp/src/**/*.jsx` обновляются на экране за долю секунды благодаря Vite HMR!

## 📂 4. Структура файлов фронтенда

Все исходники фронтенда находятся в `src/webapp/`:

```text
src/webapp/
├── index.html                   # HTML-шаблон с метатегами мобильного вьюпорта и SDK Telegram
├── vite.config.js               # Настройки сборщика Vite (базовый путь /app/, прокси API)
├── tailwind.config.js           # Цветовая палитра Matryoshka, кастомные свечения и тени
├── postcss.config.js            # Подключение плагинов Tailwind и Autoprefixer
└── src/
    ├── main.jsx                 # Точка входа React (монтирование в #root)
    ├── App.jsx                  # Главный каркас: фоновые неоновые свечения, стейт табов
    ├── index.css                # Глобальные стили, скроллбары, glassmorphism-классы
    │
    ├── services/
    │   └── telegram.js          # Обертка Telegram SDK (вибрация, expand, юзер, безопасный мок)
    │
    └── components/
        ├── layout/
        │   ├── Header.jsx       # Шапка: логотип 🌲📡, тулбары темы/языка/алертов, боковое меню
        │   └── BottomNav.jsx    # Нижний бар на 5 вкладок со светящейся плашкой (Pill Glow)
        │
        └── tabs/
            ├── DashboardTab.jsx # 🏠 Главная: статус эфира ON AIR, респот, быстрый споттинг
            ├── ClusterTab.jsx   # 📻 В эфире: кластер с фильтрами по диапазонам/модам и поиском
            ├── MapTab.jsx       # 🗺 Карта: темный контейнер, живые маркеры парков, шторка парка
            ├── SubscriptionsTab.jsx # 🔔 Подписки: позывные, парки, тумблер алертов в ЛС
            └── ProfileTab.jsx   # 👤 Профиль: позывной, статистика POTA, смена позывного, вибрация
```

## 🤖 6. Как подключить Mini App к боту в Telegram

Чтобы пользователи могли запускать приложение прямо из Telegram:

### Способ 1: Кнопка Меню бота (Menu Button) — Рекомендуется ⭐
1. Откройте диалог с **[@BotFather](https://t.me/BotFather)** в Telegram.
2. Отправьте команду: `/mybots`.
3. Выберите вашего бота (`@ru_pota_bot`).
4. Нажмите **Bot Settings** -> **Menu Button** -> **Configure menu button**.
5. Отправьте URL вашего сервера:
   ```text
   https://ваш-домен.ru/app
   ```
6. Введите название кнопки, например: `🌲 RU-POTA Hub` или `📱 Открыть Mini App`.
7. Теперь слева от поля ввода текста в Telegram появится постоянная кнопка вызова приложения!

### Способ 2: Inline-кнопка в сообщениях бота
В любом сообщении Telegraf можно добавить кнопку с `web_app`:
```javascript
ctx.reply('Откройте интерактивный кластер RU-POTA:', {
  reply_markup: {
    inline_keyboard: [[
      { text: '📱 Открыть RU-POTA Hub', web_app: { url: 'https://ваш-домен.ru/app' } }
    ]]
  }
});
```

## 📡 8. REST API Эндпоинты Telegram Mini App

Все запросы к API отправляются по префиксу `/api/tma/` и автоматически подписываются заголовком `Authorization: tma <initData>` (или `X-Dev-Mock: true` при локальной разработке):

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/api/tma/me` | Профиль оператора, статус подтверждения позывного, активный спот (`last_spot_data`), статистика POTA и счетчик подписок |
| `GET` | `/api/tma/spots` | Живой кластер спотов с поддержкой фильтров `?scope=ru\|world&band=40m&mode=SSB&search=...` (кэшируется на 15 сек) |
| `POST` | `/api/tma/spots` | Публикация спота одобренным оператором (запись в БД, пост в канал, отправка в POTA API и рассылка подписчикам) |
| `POST` | `/api/tma/spots/qrt` | Завершение работы в эфире (очистка текущего активного спота) |
| `GET` | `/api/tma/subscriptions` | Список персональных подписок пользователя на позывные и парки |
| `POST` | `/api/tma/subscriptions` | Добавление подписки (`{ type: 'callsign'\|'park', target: 'R9OGL'\|'RU-0073' }`) |
| `DELETE` | `/api/tma/subscriptions/:id` | Удаление подписки по ID |
| `POST` | `/api/tma/callsign/request` | Подача заявки на привязку или смену позывного (`{ newCallsign: '...' }`) |
