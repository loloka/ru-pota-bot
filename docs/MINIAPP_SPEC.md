# Техническая спецификация: RU-POTA Telegram Mini App (TMA) 🌲📡

Документ описывает архитектуру, интерфейс, дизайн-систему и функционал веб-приложения **Telegram Mini App (Web App)** для сообщества **Parks on the Air (RU-POTA)**.

---

## 🎯 1. Концепция и цели

**RU-POTA Mini App** — это современное высокопроизводительное веб-приложение, работающее бесшовно прямо внутри Telegram (на iOS, Android, macOS и Windows Desktop).

Оно сохраняет все возможности Telegram-бота, но кардинально расширяет пользовательский опыт (UX) за счет:
1. **Интерактивности**: живая интерактивная карта парков с GPS, поиск и автокомплит в реальном времени.
2. **Визуального дизайна премиум-уровня**: эстетика темной темы (Deep Slate / Cyber / Dark Navy) с мягкими стеклянными карточками (Glassmorphism), неоновыми акцентами, микроанимациями и тактильным откликом (Haptic Feedback).
3. **Удобства**: переключение между 5 ключевыми разделами через нижнюю навигационную панель (Bottom Navigation Bar) без необходимости отправлять команды в чат.

## 🎨 2. Дизайн-система и UI (на основе референса Matryoshka)

### 2.1. Цветовая палитра и тема
- **Фон приложения (Background)**: Глубокий темный `rgb(11, 15, 25)` / `#0b0f19` с мягкими градиентными свечениями на фоне.
- **Карточки и контейнеры (Surface)**: `#131b2e` / `rgba(255, 255, 255, 0.04)` с тонким полупрозрачным бордером `#1e293b`.
- **Основной акцент (Accent / Primary)**: Изумрудно-зеленый (POTA Forest) `#10b981` и радиолюбительский ультрамарин `#3b82f6`.
- **Активный таб в Bottom Bar**: Сияющая подсветка активной плашки (как на референсе) с индикатором.
- **Типографика**: Чистые системные шрифты (Inter / Roboto / SF Pro), контрастная белая и светло-серая иерархия текста.

### 2.2. Верхняя панель (Header)
- **Слева**: Логотип с сосной/вышкой 🌲📡 и брендинг `RU-POTA Hub`.
- **Справа (быстрые тулбары)**:
  - 🌙/☀️ Переключатель темы (Dark / Light)
  - 🔔 Колокольчик уведомлений (алерты кластера)
  - 🇷🇺/🇬🇧 Переключатель языка (`RU` / `EN`)
  - ≡ Боковое меню быстрых настроек

### Вкладка 1: 🏠 Главная (Dashboard)
Центральный пульт управления радиолюбителя при открытии Mini App:

1. **Приветствие оператора**:
   - `Добро пожаловать, {Имя}!` (подтягивается из Telegram).
   - Бейдж статуса: `[★ R9OGL — Активатор]` (зеленая/синяя плашка с позывным и статусом регистрации).
2. **Виджет «Мой статус спота»**:
   - **Если оператор сейчас в эфире**:
     - Карточка с пульсирующим зеленым индикатором `● ON AIR`.
     - Парк, частота, модуляция, таймер авто-респота (`Респот через 04:30`).
     - Быстрые кнопки: `✏️ Изменить частоту`, `📢 Респот`, `⏹ Завершить активацию (QRT)`.
   - **Если не в эфире**:
     - Крупная заметная кнопка `+ Отправить спот в эфир` (открывает модальное окно подачи спота в 2 клика).
3. **Виджет «Кто сейчас в эфире (RU / СНГ)»**:
   - Компактный горизонтальный слайдер или мини-список текущих активных станций.
   - Ссылка `Смотреть все (N) →`, ведущая на вкладку «В эфире».
4. **Сетка быстрых показателей (2 колонки, как в референсе)**:
   - **📊 Моя статистика >**: Активаций: `12` | Сработано парков: `84` | QSO: `420`.
   - **🔔 Мои подписки >**: Отслеживается: `5 операторов`, `3 парка`.

---

### Вкладка 2: 📻 В эфире (Кластер и споты)
Продвинутый кластер реального времени:

1. **Фильтры и селекторы в 1 клик**:
   - Кнопки-переключатели: `🇷🇺 Только RU/СНГ` / `🌐 Весь мир`.
   - Фильтры по диапазонам: `Все`, `40m`, `20m`, `15m`, `10m`, `2m`.
   - Фильтры по модам: `Все`, `SSB`, `CW`, `FT8/FT4`, `FM`.
   - Поисковая строка: мгновенный поиск по позывному оператора, споттеру или коду парка.
2. **Карточки спотов (Feed)**:
   - Позывной крупно с флагом страны и бэйджем модуляции (`SSB`, `CW` и т.д.).
   - Код парка (с переходом на карту), название заповедника и локация (RDA / State).
   - Частота в МГц (`14.267 MHz`), время давности (`2 мин назад`).
   - Комментарий спота и позывной споттера.
   - Кнопка быстрого действия: `🔔 Подписаться на оператора` или `🗺 Показать на карте`.
3. **Автообновление (Live Pull)**:
   - Мягкая анимация обновления без дергания экрана (SWR / WebSockets).

---

### Вкладка 3: 🗺 Парки и Интерактивная карта
То, чего невозможно сделать в обычном чате Telegram:

1. **Полноэкранная интерактивная карта (Leaflet / MapLibre / OpenStreetMap / Яндекс)**:
   - Темная стилизация карты под интерфейс приложения.
   - Маркеры парков POTA с кластеризацией.
   - **Зеленые пульсирующие маркеры**: парки, в которых *прямо сейчас* идет активация! При клике сразу видна частота и позывной.
   - Обычные маркеры: парки программы RU-POTA с кодами (`RU-0001`, `RU-0073`...).
2. **Карточка парка (Bottom Sheet)**:
   - При тапе по маркеру снизу плавно выезжает карточка:
     - Название парка, регион, RDA-район, координаты.
     - Кнопка `🧭 Маршрут` (открыть в Яндекс.Картах / Google Maps).
     - Кнопка `🔔 Подписаться на парк`.
     - История последних активаций и список лучших охотников.

### Вкладка 4: 🔔 Мои подписки
Управление персональными уведомлениями:

1. **Счетчик и сегменты**:
   - Переключатель `Позывные (3)` и `Парки (2)`.
2. **Быстрое добавление**:
   - Поле ввода с умным автокомплитом: при вводе `R9` предлагает зарегистрированных операторов, при вводе `RU-` предлагает список парков с названиями.
3. **Список активных подписок**:
   - Карточки с возможностью удалить в один свайп (Swipe-to-delete) или по кнопке `🗑`.
   - Переключатель (Toggle Switch) `Уведомления в ЛС: Вкл / Выкл`.

---

### Вкладка 5: 👤 Профиль и Настройки
Личный кабинет радиолюбителя:

1. **Шапка профиля**:
   - Аватарка Telegram, Имя, Фамилия, `@username`.
   - Основной радиолюбительский позывной (с возможностью подать заявку на смену прямо тут).
2. **Подробная статистика POTA**:
   - Прогресс активатора: уникальные парки, общее число выездов, QSO по диапазонам и модам.
   - Прогресс охотника: подтвержденные референции, дипломы POTA.
3. **Настройки приложения**:
   - Звуковые оповещения / Тактильный отклик (Haptic Feedback) при нажатии кнопок.
   - Выбор любимых диапазонов по умолчанию.
   - Ссылка на чат поддержки и документацию сообщества.

## 🛠 4. Архитектура и Технический стек

### 4.1. Frontend (Клиент Mini App)
- **Фреймворк**: Vite + Vue 3 / React (или легковесный Vanilla SPA с Tailwind CSS).
- **Стилизация**: Tailwind CSS (Dark Mode по умолчанию) + Headless UI / Lucide Icons.
- **Интеграция с Telegram**: `@telegram-apps/sdk` или нативный `Telegram.WebApp`:
  - `Telegram.WebApp.expand()` — автоматическое раскрытие на весь экран.
  - `Telegram.WebApp.HapticFeedback` — вибрации при тапах по кнопкам и переключении табов.
  - `Telegram.WebApp.themeParams` — гармонизация с темой пользователя.
  - `Telegram.WebApp.BackButton` — системная кнопка «Назад» в Android/iOS.
- **Карты**: Leaflet.js с темным тайловым слоем CartoDB Dark Matter или Яндекс.Карты API.

### 4.2. Backend (Серверная часть)
- **Node.js Express**: использует уже существующий бэкенд проекта (`src/web/` и `src/db/database.js`).
- **Безопасная аутентификация**:
  - Валидация `Telegram.WebApp.initData` с проверкой криптографической подписи HMAC-SHA256 через `BOT_TOKEN`.
  - Никаких логинов и паролей — пользователь авторизуется автоматически и надежно на основе своей сессии Telegram.
- **REST API эндпоинты**:
  - `GET /api/me` — профиль пользователя, позывной, статистика.
  - `GET /api/spots` — фильтрованный кластер спотов в реальном времени.
  - `POST /api/spots` — публикация нового спота.
  - `GET /api/parks` — каталог парков с координатами для карты.
  - `GET /api/subscriptions` & `POST /api/subscriptions` — управление подписками.

## 📋 5. План реализации (Roadmap разработки Mini App)

1. **Этап 1: Каркас и UI-оболочка (Frontend Skeleton)**:
   - Инициализация проекта Vite + Tailwind CSS в директории `src/webapp/`.
   - Реализация базового темного лейаута: Header (логотип, тулбары) + Bottom Navigation Bar (5 вкладок).
   - Интеграция Telegram WebApp SDK и тактильного отклика (Haptics).

2. **Этап 2: Backend API и Авторизация**:
   - Создание мидлвара проверки `initData` в Express.
   - Разработка эндпоинтов `/api/me`, `/api/spots`, `/api/parks`, `/api/subscriptions`.

3. **Этап 3: Разработка экранов**:
   - Экран 1: Главный дашборд с виджетами и карточками.
   - Экран 2: Интерактивный кластер «В эфире» с фильтрами по модам/диапазонам.
   - Экран 3: Интерактивная карта парков (Leaflet) с кластеризацией и живыми маркерами.
   - Экран 4: Управление подписками с поиском и свайпами.
   - Экран 5: Карточка профиля и статистика.

4. **Этап 4: Интеграция с ботом и деплой**:
   - Добавление кнопки запуска Web App в меню бота (`Bot Settings -> Menu Button`).
   - Добавление кнопки Web App в Reply-клавиатуру и инлайн-кнопки постов.
   - Тестирование на мобильных устройствах iOS/Android.
