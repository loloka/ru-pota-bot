# Спецификация функции /onair («Кто в эфире прямо сейчас») 📻

## 1. Цель и назначение
Предоставить радиолюбителям (активаторам и охотникам) компактную, мгновенную сводку всех станций из RU/СНГ региона, которые работают в эфире прямо сейчас (за последние 30–40 минут).

---

## 2. Источник данных и фильтрация
1. **Источник данных:** POTA API (`https://api.pota.app/spot/activator` через метод `potaApi.getSpots()`).
2. **Гео-фильтр:** Префиксы парков из переменной окружения `ALLOWED_PREFIXES` (по умолчанию: `RU-,BY-,KZ-`).
3. **Временной фильтр:** Споты за последние 40 минут (сравнение времени спота с текущим временем UTC).
4. **Дедупликация и группировка:**
   - Если один и тот же активатор был заспочен несколько раз (например, сменил частоту или диапазон), в списке отображается только **самый свежий спот** оператора.
   - Сортировка списка: по убыванию времени (самые свежие споты наверху).

---

## 3. Форматирование сообщения

### Пример вывода:
```text
📻 СЕЙЧАС В ЭФИРЕ (3)

• <b><a href="https://next.pota.app/profile/R9OGL">R9OGL/P</a></b> @ <b><a href="https://next.pota.app/park/RU-0065">RU-0065</a></b>
  Частота: 7.140 MHz (SSB) | 5 мин назад

• <b><a href="https://next.pota.app/profile/RA3ABC">RA3ABC</a></b> @ <b><a href="https://next.pota.app/park/RU-0120">RU-0120</a></b>
  Частота: 14.044 MHz (CW) | 18 мин назад

• <b><a href="https://next.pota.app/profile/UB5DDD">UB5DDD/P</a></b> @ <b><a href="https://next.pota.app/park/BY-0012">BY-0012</a></b>
  Частота: 14.285 MHz (SSB) | 35 мин назад
```

Если активных станций нет:
```text
📻 <b>Сейчас в эфире</b>

На данный момент в кластере POTA нет активных станций из нашего региона (за последние 40 минут).
Вы можете стать первым — отправьте спот через /spot!
```

Кнопки под сообщением:
- 🔄 Обновить (inline callback для быстрого обновления списка без повторного ввода команды).
- ❌ Удалить сообщение (callback `delete_msg:<userId>`).

---

## 4. Поведение в чатах (ЛС и Группы)
- **В личных сообщениях (ЛС):** Обычный ответ пользователю с inline-кнопками.
- **В публичных группах / супергруппах:**
  - Автоматическое удаление сообщения пользователя с вызовом команды (`deleteUserMessage(ctx)`).
  - Сообщение от бота содержит инлайн-кнопку «❌ Удалить сообщение», доступную только автору запроса или администраторам.

---

1. **Главная клавиатура (Reply Keyboard в ЛС):**

2. **Команды и обработчики:**
   - Регистрация команды `/onair` в `src/bot/commands/onair.js`.
   - Регистрация слушателя `bot.hears('📻 Кто в эфире', onairHandler)`.
3. **Обновление справки:**
   - Добавление описания команды в `/help` и приветствие `/start`.
   - Обновление `COMMANDS.md` и `README.md`.
